# Dimineața Magică

Kindergarten morning-meeting web app (Romanian): nature calendar, attendance with photos, emotions game, seasons game.

Open: **https://mocanuEmanuel.github.io/dimineata-magica/**

Data (kids list, photos, marks, per-date calendar game) is stored only in the browser's localStorage. Use **Salvează copie** on the Prezență page to export a JSON backup (kids + attendance + calendar); **Încarcă copie** restores it on any device/browser.
